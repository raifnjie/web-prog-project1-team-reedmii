About the Team

Quest Explorer is a static HTML and CSS project for CSC 4370/6370 (Track B, Adventure Pack).

Raif Njie

Page structure, home and about layouts, transitions and transforms, accessibility checks.

Michael Tewabe

Design system, map and mission layouts, keyframe animations, responsive testing.

Project story

We wanted a first portfolio project that feels like a journey, not a list of pages. The map, mission, and route pages show progress at a glance.

Design decisions

  • Semantic landmarks, one h1 per page, and a skip link on every page.
  • Status is always shown with an icon and a text label, never color alone.
  • Transforms instead of top or margin, so hover effects never shift the layout.
  • All animations are wrapped in a prefers-reduced-motion check.
  • The checkpoint route is an ordered list, because the order matters.

Tools used

VS Code, Git and GitHub, Chrome DevTools, the W3C validators, and Google Fonts (Cinzel and Inter).
